    Settings

    Converting

    Convert files as soon as they open
    Saves an Excel copy right away, with your layout choices. When this is off, files open in the preview first.
    Save Excel files
    Sheets with more than one table
    Each table on its own Excel sheet, or all of a sheet’s tables on one Excel sheet, placed as in Numbers. You can still change any sheet in the preview.
    Add a Contents sheet
    Starts the Excel file with a sheet that links to every table, like the summary sheet Numbers can add when it exports.

    Privacy

    Your files stay on this PC
    Numbers Converter does all of its work on your computer. It never uploads your files, needs no account and collects no usage data. It only goes online to check GitHub for updates, which you can turn off below.

    Updates

    Check for updates automatically
    Looks for new versions on GitHub when the app starts and every 6 hours. They download in the background and install the next time you restart. When this is off, the app never goes online on its own.
